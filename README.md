## 🧠 Mental Health Score Prediction

**End-to-end Machine Learning application deployed on AWS Lambda.**

Predicts mental health scores from lifestyle and behavioral data using a trained Scikit-Learn pipeline, FastAPI, Docker, and serverless AWS infrastructure.

### 🔄 Flow

```text
👤 User
   ↓
🌐 Web Interface
   ↓
☁️ AWS Lambda URL
   ↓
⚡ FastAPI + Mangum
   ↓
📊 Pandas Preprocessing
   ↓
🧠 Scikit-Learn Pipeline
   ↓
📈 Mental Health Score
   ↓
🌐 Prediction Response
```

## 🩺 MedBot — RAG Medical AI Assistant
RAG-based medical AI assistant powered by a local Qwen LLM.
Uses a 4,500+ page medical encyclopedia, semantic search, Pinecone, and local Qwen inference through Ollama to generate grounded answers with page-level citations.

### 🔄 Flow
```
📚 Medical Encyclopedia
        ↓
📄 Document Processing
        ↓
✂️ Chunking
        ↓
🔢 Embeddings
        ↓
🗄️ Pinecone Vector DB
        ↓
👤 User Question
        ↓
🔎 Semantic Search
        ↓
📖 Retrieved Context
        ↓
🦙 Qwen + Ollama
        ↓
💬 Grounded Answer
        ↓
📌 Page Citations
```
🔗 GitHub Repo → https://github.com/Saish-Chavan10/MedBot-RAG-Assistant

🔗 View Project → https://cytfru4sqo3ug74ygxzjunv4ve0xdhao.lambda-url.ap-south-1.on.aws/
